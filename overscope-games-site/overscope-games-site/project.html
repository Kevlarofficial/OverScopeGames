Project Asphyx

You can't see it. You can feel it filling the room.

BRF.01

Overview

A horror game built around a gas-based intelligence — an unseen predator that reads a station's air the way most monsters read footsteps.

The station itself is the second monster: a single, seamless environment with no load screens, meaning nowhere to hide behind a loading bar and no safe cut between rooms. Every system underneath — patrol logic, player systems, environmental interaction — is built in-house to hold that illusion together.

Systems in place

Interactive station computers

Replicated, in-world terminals players can actually use — not set dressing.

SYS-02

Custom class selection & spawn

Multiple game modes, each with its own class selection and spawn logic built around it.

Spectator & death systems

A custom spectator pawn and death flow, so leaving the round doesn't mean leaving the tension.

Per-class mechanics

Every playable class has mechanics unique to it — not reskins of one shared kit.

No-load station

One giant, continuous space station environment. No loading screens, no seams to hide behind.

SYS-06

Atmosphere-driven AI

The central threat tracks the station's air, not footsteps — built to make hiding a losing strategy.
